# User Onboarding

Sagip helps a person set aside testnet funds for someone they love while keeping the experience understandable for non-technical family members.

## Create an account

1. Register using a mobile number and six-number PIN.
2. Add and verify an email address when account recovery and reminders are needed.
3. Save recovery information in a secure place.

## Set up a wallet

Choose one option:

- **Create a new wallet:** Sagip creates a testnet account and shows the recovery key once for confirmation.
- **Use an existing wallet:** Import a compatible testnet recovery key.

Recovery keys control the wallet. Never share them in chat, email, screenshots, public issues, or support messages.

## Add a loved one

Add the person's name and mobile number. The mobile number helps with claim-link recovery.

Use a separate person when configuring a backup beneficiary.

## Set aside money

1. Choose the loved one.
2. Enter the testnet amount.
3. Select the check-in frequency.
4. Optionally add a backup person.
5. Review the date and receive rules.
6. Confirm the transaction.
7. Save or print the claim link or QR card.

## Check in

Open the active safety net and tap **I am okay** before the window ends. The application refreshes the Stellar time condition and records the transaction.

## Take the money back

The sender can reclaim an active safety net while they remain an unconditional claimant.

## Family receive flow

When the sender's check-in window lapses:

1. The loved one opens the claim link.
2. They verify the intended recipient details.
3. They tap **Receive**.
4. The application submits the testnet claim and displays the transaction record.

When a backup is configured, receiving may create a new guarded balance requiring the primary receiver to continue check-ins.

## Lost access

A claim link can be recovered by asking the sender to share it again, using the saved mobile number, or using a printed claim card.

A lost phone does not itself remove funds from Stellar, but losing the claim link or wallet recovery key can make access difficult.

## Important limits

- Sagip currently uses Stellar testnet assets.
- Test assets have no real monetary value.
- Real peso deposits and withdrawals are not implemented.
- Check-in lapse is not legal death verification.
- Sagip is not a will, insurance product, or regulated financial service.
